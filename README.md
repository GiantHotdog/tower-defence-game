# **Kernel Panic**

This is a tower defence game prototype built using the Godot engine. It is heavily inspired by 1990s Unix systems, hence the name.

---

**⚠️ The demo is live at [https://gianthotdog.itch.io/Kernel-Panic](http://gianthotdog.itch.io/Kernel-Panic)**

---

![Example Level.](/Screenshots/Screenshot4.png)

---

### **System Specifications:**

- Multiple levels
- GRUB-style menu
- A settings menu with:
  - Audio settings
- A config file system so settings persist across plays of the game
- Towers with adjustable targeting priorities
- Custom resources to handle:
  - Upgrades
  - Enemy counts in waves

---

### **Planned features:**

- A greater variety of:
  - Towers
  - Levels
  - Enemies
- A UI overhaul to give a unified aesthetic
