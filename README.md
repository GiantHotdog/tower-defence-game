# **Kernel Panic**

Hold off malware to give your firewall time to be repaired in this tower defence game prototype built using the Godot engine! It is heavily inspired by 1990s Unix systems, hence the name.

---

**⚠️ The demo is live at [https://gianthotdog.itch.io/Kernel-Panic](http://gianthotdog.itch.io/Kernel-Panic)**

---

### **System Specifications:**

- Multiple levels including a tutorial
- GRUB-style menu
  - A settings menu with:
    - Audio settings
    - Credits
    - VSync settings
- A config file system so settings persist across play sessions
- An upgrade tree that contains global upgrades to towers and XP gains
  - An XP and skill point system for purchasing those upgrades
- 4 types of towers with adjustable targeting priorities
- Several enemy types
- Custom resources to handle:
  - Single tower upgrades
  - Enemy counts in waves
  - Global upgrades

---

## **Controls:**

- Enter to skip startup sequence
- Click to select / interact / modify values

---

### **AI:**

AI was used to write about 50 lines of code for the two shaders, and very occasionally for solving persistent bugs. It was only used for bug fixes after I tried repeatedly and failed to find a solution myself.
It was also used for some feedback on aesthetic choices. All assets were designed by hand. All AI code was reviewed before implementation
